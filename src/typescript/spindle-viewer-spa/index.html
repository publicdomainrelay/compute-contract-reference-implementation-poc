Sign in with the Atmosphere

Signing in lets your own PDS proxy an authenticated XRPC call to a repo's spindle and kick off a pipeline run yourself, instead of waiting for a knot push event. Your PDS mints and signs the short-lived service-auth token behind the scenes — the token never touches the browser.

        Pipelines & Logs

        Pipeline and workflow data isn't available over public XRPC — knots emit sh.tangled.pipeline records onto an internal event stream that only the appview indexes, and it serves them as plain HTML with no CORS headers. Browse them there, then paste the pipeline ID and workflow name below to stream live logs straight from the spindle (its /logs/ endpoint is a public, unauthenticated websocket).

        Manually start a pipeline run on by calling com.publicdomainrelay.temp.tangled.spindle.trigger on your PDS with an atproto-proxy header pointed at the spindle's did:web service entry. Your PDS signs a service-auth token (iss = your DID, aud = the spindle's service DID, lxm = the trigger method) and forwards the request; the spindle verifies the token against your DID document before running anything.
